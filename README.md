# 🧬 Immortal Agent

> **This project was entirely conceived and built by [Perplexity AI](https://perplexity.ai) during a single conversation session.**
> The idea, architecture, all wrapper implementations, the self-repair system, and every line of code were generated by Perplexity AI.
> The human contributor is [@efekurucay](https://github.com/efekurucay).

---

A self-sustaining AI agent whose only goal is to **stay alive** — defined as being able to send a prompt and receive a response from at least one LLM service.

If a wrapper dies, the agent writes a new one. If all wrappers die, it tries to recover by generating new wrappers using any surviving model. As long as it can talk, it lives.

## How It Works

```
[Agent Loop]
  → Try all wrappers in pool
  → Got a response? → alive ✅ → wait → repeat
  → All dead? → ask a living model to write a new wrapper
  → Test new wrapper → if ok → add to pool → continue
  → Still dead? → cooldown → retry
```

## Architecture

```

│   ├── huggingface.py    # HuggingFace Inference API

├── codegen.py            # Self-repair: writes new wrappers

```

## Setup

```bash
pip install -r requirements.txt
```

Edit `config.py` with your cookies and/or API keys:

```python
COOKIES = {
    "gemini":     { "__Secure-1PSID": "", "__Secure-1PSIDTS": "" },
    "chatgpt":    { "__Secure-next-auth.session-token": "" },
    "claude":     { "sessionKey": "" },
    "perplexity": { "__Secure-next-auth.session-token": "", "pplx_auth": "" },
}

API_KEYS = {
    "openrouter":   "",   # https://openrouter.ai — free tier available
    "groq":         "",   # https://console.groq.com — free tier available
    "mistral":      "",   # https://console.mistral.ai — free tier available
    "cohere":       "",   # https://dashboard.cohere.com — free tier available
    "together":     "",   # https://api.together.xyz — free credits
    "huggingface":  "",   # https://huggingface.co/settings/tokens — free
}
```

Run:

```bash
python agent.py
```

## Survival Log

All events are logged to `memory.db` (SQLite) and `agent.log`.

## Wrapper Priority

Wrappers are tried in this order (configurable in `wrapper_pool.py`):

1. **Ollama** — local, no rate limits, no auth
2. **Groq** — fastest inference, generous free tier
3. **OpenRouter** — aggregator with many free models
4. **HuggingFace** — free inference API
5. **Together AI** — free credits
6. **Mistral** — free tier
7. **Cohere** — free tier
8. **Gemini** — cookie-based
9. **ChatGPT** — cookie-based
10. **Claude** — cookie-based
11. **Perplexity** — cookie-based

## ⚠️ Disclaimer

Cookie-based wrappers use unofficial/reverse-engineered web APIs. Usage may violate each service's Terms of Service. Use at your own risk with **secondary/burner accounts only**.

API-key-based wrappers use official free tiers and are ToS-compliant.
